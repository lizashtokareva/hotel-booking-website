# Hotel Booking Website

## Описание
Сервис для просмотра доступных отелей и бронирований. Позволяет просматривать, добавлять, изменять, удалять номера и их бронирования.
## Технологии
Python, Django, SQLite.

## Установка

python -m pip install -r requirements.txt

## Запуск

Создание виртуального окружения:
python -m venv .venv

Активация на Windows в PowerShell:
.\.venv\Scripts\Activate.ps1

Создание таблиц в базе: 
python manage.py migrate

Запуск сервера:
python manage.py runserver

Запуск тестов:
python manage.py test hotels
